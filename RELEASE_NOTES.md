# Forge syntax 0.1.0

Independent Forge support for Sublime Text 4: syntax highlighting, snippets, comment toggling, indentation settings and explicit build/check/run commands. No LSP or language server is required for syntax highlighting.

For language-server features install [LSP-Forge](https://github.com/forge-language/sublime-text) and LSP separately. This package replaces the syntax resources previously bundled with LSP-Forge 0.1.0.
